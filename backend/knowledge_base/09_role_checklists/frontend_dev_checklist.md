# Onboarding Checklist: FRONTEND DEV

This document outlines the standardized 20-step onboarding sequence for the **frontend dev** role at O.N.E.

## Sequential Tasks

1. [ ] **Step 01**: Request GitHub Access to Corporate Repositories
2. [ ] **Step 02**: Install Node.js v20 LTS and NVM
3. [ ] **Step 03**: Install Visual Studio Code and Recommended Extensions (ESLint, Prettier, Tailwind)
4. [ ] **Step 04**: Clone the O.N.E. Frontend Repository
5. [ ] **Step 05**: Configure Environment Variables (.env.local)
6. [ ] **Step 06**: Install NPM Dependencies (npm install)
7. [ ] **Step 07**: Launch Local Development Server (npm run dev)
8. [ ] **Step 08**: Review Frontend Architecture and Directory Structure
9. [ ] **Step 09**: Review Component Library and Design System Rules
10. [ ] **Step 10**: Setup React Developer Tools and Redux/State Inspector
11. [ ] **Step 11**: Configure ESLint and Code Formatter Rules
12. [ ] **Step 12**: Run Unit and Component Tests (npm run test)
13. [ ] **Step 13**: Explore Figma UI Mockups and Specs
14. [ ] **Step 14**: Inspect API Client and Endpoint Integration Setup
15. [ ] **Step 15**: Implement a Sample Component or Fix a UI Starter Issue
16. [ ] **Step 16**: Verify Responsive Breakpoints and Mobile Viewports
17. [ ] **Step 17**: Test Accessibility and ARIA Standard Compliance
18. [ ] **Step 18**: Submit Pull Request for Initial Dev Assignment
19. [ ] **Step 19**: Pass Code Review and Code Coverage Checks
20. [ ] **Step 20**: Complete Frontend Developer Onboarding Sign-off
