# Onboarding Checklist: CLOUD

This document outlines the standardized 20-step onboarding sequence for the **cloud** role at O.N.E.

## Sequential Tasks

1. [ ] **Step 01**: Request AWS/GCP Cloud Console IAM Credentials
2. [ ] **Step 02**: Install AWS CLI, Google Cloud SDK, and Kubernetes CLI (kubectl)
3. [ ] **Step 03**: Install Terraform, OpenTofu, and Helm Package Manager
4. [ ] **Step 04**: Clone Cloud Infrastructure as Code (IaC) Repositories
5. [ ] **Step 05**: Configure Local Cloud Credentials and MFA Profiles
6. [ ] **Step 06**: Validate Terraform State Storage and Locking Setup
7. [ ] **Step 07**: Review Production and Staging Cloud Architecture Diagrams
8. [ ] **Step 08**: Inspect VPC, Subnet, and Security Group Configurations
9. [ ] **Step 09**: Run terraform plan on Staging Environment
10. [ ] **Step 10**: Verify Kubernetes Cluster Status and Node Pools
11. [ ] **Step 11**: Audit IAM Roles, Policies, and Service Accounts
12. [ ] **Step 12**: Inspect CloudWatch/Datadog Monitoring and Alerting Dashboards
13. [ ] **Step 13**: Test Infrastructure Deployment in Sandbox Account
14. [ ] **Step 14**: Review Secrets Management (AWS Secrets Manager / Vault)
15. [ ] **Step 15**: Audit SSL/TLS Certificate Rotation and Ingress Controllers
16. [ ] **Step 16**: Execute Disaster Recovery and Backup Verification Drill
17. [ ] **Step 17**: Deploy Minor Infrastructure Update via CI/CD Pipeline
18. [ ] **Step 18**: Review Cloud Security and Compliance Standard Baselines
19. [ ] **Step 19**: Document Cloud Infrastructure Update Runbooks
20. [ ] **Step 20**: Complete Cloud Engineer Onboarding Sign-off
