# Onboarding Checklist: DATABASE DEV

This document outlines the standardized 20-step onboarding sequence for the **database dev** role at O.N.E.

## Sequential Tasks

1. [ ] **Step 01**: Request Database Administrative Credentials and Access Grants
2. [ ] **Step 02**: Install PostgreSQL Client (psql), DBeaver, or DataGrip
3. [ ] **Step 03**: Configure Supabase Dashboard Access and CLI Tooling
4. [ ] **Step 04**: Clone Database Schemas and Migration Repository
5. [ ] **Step 05**: Review ER Diagrams and Core Table Relationships
6. [ ] **Step 06**: Inspect Table Indexes, Foreign Keys, and Constraints
7. [ ] **Step 07**: Run Local PostgreSQL Instance via Docker Container
8. [ ] **Step 08**: Execute Schema Migrations and Seed Test Datasets
9. [ ] **Step 09**: Audit Slow Query Logs and EXPLAIN ANALYZE Execution Plans
10. [ ] **Step 10**: Review Row Level Security (RLS) Policies on Supabase
11. [ ] **Step 11**: Verify Connection Pooling Configs (PgBouncer/Supabase Pooler)
12. [ ] **Step 12**: Inspect Database Backup Routines and Point-in-Time Recovery
13. [ ] **Step 13**: Optimize High-Traffic Database Indexes and Materialized Views
14. [ ] **Step 14**: Implement New Schema Migration for Upcoming Feature
15. [ ] **Step 15**: Test Migration Rollback Procedures in Staging DB
16. [ ] **Step 16**: Review Database Security and Data Encryption at Rest/Transit
17. [ ] **Step 17**: Monitor Connection Spikes and Lock Contention Dashboards
18. [ ] **Step 18**: Submit Database PR and Migration Guide
19. [ ] **Step 19**: Perform Staging Database Load Test
20. [ ] **Step 20**: Complete Database Developer Onboarding Sign-off
