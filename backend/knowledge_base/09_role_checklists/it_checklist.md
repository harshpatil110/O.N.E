# Onboarding Checklist: IT

This document outlines the standardized 20-step onboarding sequence for the **IT** role at O.N.E.

## Sequential Tasks

1. [ ] **Step 01**: Receive Corporate Laptop and Hardware Credentials
2. [ ] **Step 02**: Configure MDM, Disk Encryption, and Endpoint Security
3. [ ] **Step 03**: Setup Password Manager and Enforce 2FA/MFA
4. [ ] **Step 04**: Provision Corporate Email, Slack, and Google Workspace Accounts
5. [ ] **Step 05**: Configure VPN and Secure Network Tunnel Access
6. [ ] **Step 06**: Review IT Helpdesk Ticketing System (Jira Service Desk)
7. [ ] **Step 07**: Grant Access to Identity Provider (Okta / Azure AD / Entra ID)
8. [ ] **Step 08**: Audit Hardware Inventory and Asset Tracking Logs
9. [ ] **Step 09**: Install Standard Corporate Software Suite and Developer Utilities
10. [ ] **Step 10**: Review Security Baseline and Data Privacy Policy Documents
11. [ ] **Step 11**: Configure Automated System Updates and Patch Management
12. [ ] **Step 12**: Set Up Employee Onboarding and Offboarding Workflows
13. [ ] **Step 13**: Verify Single Sign-On (SSO) Integrations for Developer Tools
14. [ ] **Step 14**: Test Wi-Fi Certificate and Office Network Provisioning
15. [ ] **Step 15**: Inspect IT Security Incident Response Playbooks
16. [ ] **Step 16**: Conduct IT Helpdesk Ticket Triage Shadow Session
17. [ ] **Step 17**: Automate User Provisioning Scripting Task
18. [ ] **Step 18**: Audit User Access Logs and License Consumption Metrics
19. [ ] **Step 19**: Publish IT Knowledge Base Guide Update
20. [ ] **Step 20**: Complete IT Specialist Onboarding Sign-off
