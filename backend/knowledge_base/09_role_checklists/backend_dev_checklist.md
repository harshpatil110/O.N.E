# Onboarding Checklist: BACKEND DEV

This document outlines the standardized 20-step onboarding sequence for the **backend dev** role at O.N.E.

## Sequential Tasks

1. [ ] **Step 01**: Request Access to Corporate AWS and GitHub Repositories
2. [ ] **Step 02**: Install Python 3.12 and Poetry/Pipenv
3. [ ] **Step 03**: Install Docker Desktop and Container Tooling
4. [ ] **Step 04**: Clone the O.N.E. Backend FastAPI Repository
5. [ ] **Step 05**: Create Local Virtual Environment and Install Dependencies
6. [ ] **Step 06**: Configure Local Environment Variables (.env)
7. [ ] **Step 07**: Setup and Run Local PostgreSQL Database via Docker
8. [ ] **Step 08**: Run Alembic Database Migrations (alembic upgrade head)
9. [ ] **Step 09**: Launch Local FastAPI Server via Uvicorn
10. [ ] **Step 10**: Test API Endpoints using Swagger Docs (/docs)
11. [ ] **Step 11**: Review Core Application Architecture and ADRs
12. [ ] **Step 12**: Configure Logging and Tracing Middleware
13. [ ] **Step 13**: Run Backend Unit Test Suite (pytest)
14. [ ] **Step 14**: Inspect Authentication and JWT Security Pipeline
15. [ ] **Step 15**: Verify Database Connection Pooling and Migration Tools
16. [ ] **Step 16**: Pick and Implement First Good-First-Issue Task
17. [ ] **Step 17**: Write Integration Tests for New Endpoint
18. [ ] **Step 18**: Submit Pull Request and CI/CD Pipeline Build
19. [ ] **Step 19**: Address Code Review Feedback from Tech Lead
20. [ ] **Step 20**: Complete Backend Developer Onboarding Sign-off
